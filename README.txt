# Dr. Javed Ahmad — ENT Specialist Website

A responsive one-page clinic website for Dr. Javed Ahmad, ENT Specialist, Faisalabad.

## Files
- index.html — complete website
- style.css — responsive styling
- script.js — mobile menu + current year

## How to use
1. Open `index.html` in a browser to preview it.
2. Upload all three files to your hosting/public_html folder.
3. Replace the generated doctor placeholder in the hero card with an authorized professional photo if the doctor/clinic provides one.
4. Confirm clinic timings, consultation fee and exact address with the clinic before publishing, because these details can change.
